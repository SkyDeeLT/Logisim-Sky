# Logisim Sky v1.0.0

First public release of Logisim Sky, a modern desktop-focused derivative of classic Logisim 2.7.1.

## Highlights

- modernized desktop interface with five themes;
- autosave and crash recovery;
- circuit tabs and command palette;
- live truth-table and Karnaugh-map preview;
- real-time circuit diagnostics;
- logic analyzer and wire-network inspection;
- undo/redo history and combinational test cases;
- recent-project start screen, focus mode and improved HiDPI workflow.

## Compatibility

Logisim Sky keeps the classic Logisim 2.7.1 `.circ` serializer. UI-specific state is stored outside circuit files.

## Downloads

- **macOS Apple Silicon:** `Logisim-Sky-1.0-Apple-Silicon.zip`
- **Cross-platform Java:** `Logisim-Sky-1.0.jar`
- **Windows x64:** `Logisim-Sky-1.0-Windows-x64.exe`

## macOS first launch

Because this build is not Apple-notarized, macOS may block it on first launch. Follow the first-launch instructions included inside the macOS archive.
